# CORE Breach Enterprise (Showcase Edition)

Автономная платформа непрерывного анализа внешней поверхности атак (**EASM**) и автоматизированного контроля защищенности сетевого периметра. Платформа функционирует в режиме интеллектуального пассивного наблюдения и классификации рисков ИБ без деструктивного воздействия на исследуемые объекты.

> **Legal Notice & Guardrail:** Платформа разработана строго для авторизованного аудита безопасности (White Hat) в рамках официальных программ Bug Bounty или коммерческих соглашений. Исполнительный движок CORE ENGINE оснащен встроенным модулем жесткого контроля лимитов (`Scope Guardrail`) и аппаратно блокирует запуск процессов сканирования до верификации полномочий оператором.

## Архитектурные особенности и возможности

### 1. Автономный OSINT & Asset Discovery
Движок производит сбор, корреляцию и верификацию данных об инфраструктуре организации из независимых публичных источников, полностью исключая прямые обращения к периметру цели на этапе разведки:
* Интеллектуальный поиск поддоменов через Certificate Transparency (асинхронные цепочки запросов к `crt.sh` с автоматическим контролем таймаутов и механизмом повторных попыток).
* Пассивная агрегация данных через внешние специализированные API (интеграционные модули для подсистем класса Chaos, SecurityTrails, subfinder).
* Поиск связанных сетевых активов и доменных имен на основе анализа поисковой выдачи и многопоточного DNS-брутфорса.
* Автоматическая валидация находок с занесением в изолированный конфигурационный файл `scope.yaml` для исключения случайного сканирования внешних ресурсов.

### 2. Асинхронный Recon & Профилирование
После ручного подтверждения границ scope оператором, платформа переходит к детальному анализу доступных сервисов:
* **Сетевой анализ высокой плотности:** Асинхронный резолв (A/AAAA) и высокопроизвидительное TCP-сканирование портов с использованием паттерна `/24 expansion` (автоматическое выявление активных соседних хостов в целевой подсети).
* **Web Fingerprinting:** Определение стека технологий, версии ПО, анализ заголовков безопасности, флагов устаревшего софта и служебных конфигурационных файлов.
* **Deep Directory Fuzzing:** Многопоточный безопасный поиск скрытых директорий, резервных копий и утечек чувствительных файлов конфигурации (`.env`, `.git`) с использованием исключительно безопасных немодифицирующих `GET`-запросов.
* **Doc Hunter & Leak Evidence:** Автоматический аудит открытых файловых хранилищ, консолидация подозрительных сигналов компрометации в единую базу знаний с формированием прямых линков для аналитика ИБ.

### 3. Интеллектуальный скоринг и ИИ-аналитика (AI Intelligence Layer)
Система уходит от концепции «сырых логов» и использует гибридный подход к классификации угроз:
* **Risk Categorization:** Находки ранжируются по уровням критичности (`LOW` / `WARNING` / `CRITICAL`). В категорию `CRITICAL` попадают только верифицированные утечки секретов и открытые индустриальные (OT) порты в ИТ-контуре. Разделение потоков сканирования исключает ложные срабатывания.
* **Cognitive AI Automation:** Интеграция со слоем локальных LLM (через интерфейсы Ollama) или коммерческих ИИ-сервисов позволяет автоматически интерпретировать назначение хостов, анализировать найденные документы и готовить сводные технические конспекты для отчетов.

### 4. Отказоустойчивый Live-интерфейс
* Потоковая визуализация процесса сканирования в реальном времени с использованием асинхронного моста событий (`AsyncCoreBridge`), что предотвращает блокировку и зависание UI при экстремальных сетевых нагрузках.
* Оперативное информирование о критических инцидентах через систему асинхронных уведомлений (Telegram Alerts).

## Компоненты и стек системы

Платформа спроектирована по микросервисной модульной архитектуре и полностью адаптирована для развертывания в изолированных On-Premise / Air-Gapped контурах предприятий:

* **Core Engine:** Асинхронное ядро сканирования (`asyncio` + `httpx`), реализующее логику stealth-маскировки трафика, ротации прокси-серверов для обхода WAF, работу сетевых семафоров и жестких лимитов scope.
* **Async Bridge:** Архитектурный слой очередей событий для обеспечения неблокирующего взаимодействия между движком и интерфейсом.
* **Control Panel:** Интуитивный дашборд управления платформой на базе веб-фреймворка NiceGUI.
* **Reporting Module:** Автономная генерация детализированных корпоративных отчетов в форматах PDF и XLSX по результатам аудита периметра.
